# 標誌槽（logo slot）— 決定要掛誰的標誌

> 標誌與底色是**兩個獨立的選擇**：底色看 `../themes/`（`dark` / `light`），
> 標誌看這裡。任意組合皆可，`.md` 兩行搞定。

## 現有標誌

| `logo:` | 標誌 | 說明 |
|---|---|---|
| `none`（省略時的預設） | 無 | 每頁不掛標誌，封面與結尾也不放。給客戶的提案常用這個 |
| `tomoaid` | TomoAid | 官方原色；黑底自動加淺色底片、白底直接使用 |

```yaml
theme: dark        # 或 light
logo: tomoaid      # 或 none
底片: 自動          # 可選：自動（預設）／無
```

## ⚠️ 標誌絕對不改色

**不得為了配合背景而修改任何標誌的顏色**——那是品牌資產，改了就不是它了。

深色底放彩色標誌確實有真實的對比問題。以 TomoAid 標誌在 `#0d0f14` 上實測：

| 元素 | 對比 | 判定 |
|---|---|---|
| 四個小人（黃 / 青 / 珊瑚 / 紫） | 10.5 / 10.8 / 6.4 / 4.6 : 1 | ✅ 都夠 |
| 中央甜甜圈 亮端 `#1E6E8C` | 3.34 : 1 | ⚠️ 偏暗 |
| 中央甜甜圈 暗端 `#123E5F` | **1.72 : 1** | ❌ 幾乎看不見 |

直接放上去會變成「四個小人漂在空中、中間破一個洞」。正確解法依優先順序：

1. **用該品牌官方的反白／單色版標誌**（最佳解）——把官方版的 defs 換進標誌包【B】段，並在 frontmatter 寫 `底片：無`。
2. **改用白底**（`theme: light`）——標誌回到它被設計的底色上，不需任何加工。
3. **原色標誌 + 淺色底片**（目前黑底的預設做法）——業界標準的 keyline plate 處理，標誌一個像素都不動。

底片的外觀由**配色主題**決定（`--logo-plate-bg` / `-pad` / `-radius`），所以同一份標誌包在黑底會長出底片、在白底自動消失。

## 一份標誌包的結構

| 段 | 內容 | 貼到哪裡 | 貼幾次 |
|---|---|---|---|
| `<style>` | 只有 `--brand-name`（標誌旁的文字），不碰配色 | `<style>` 內、主題之後 | 1 |
| 【B】標誌 defs | 隱藏的 `svg` + `defs`，內含 `id="brand-mark"` | `<body>` 開頭 | 1 |
| 【C-1】每頁左上 | `.logo` ＋ `.logo-plate` | 每個 `section.slide` 第一行 | 每頁 1 |
| 【C-2】封面大標誌 | `.logo-plate.lg` | `cover` 的 `<h1>` 之前 | 1 |
| 【C-3】結尾小標誌 | `.logo-plate.sm` | `closing` 金句之後 | 1 |

`logo: none` 時全部略過。

## 要新增一個標誌（例如客戶的）怎麼做

複製 `tomoaid.html` 改名，然後：

- 把 `<defs>` 內容換成該品牌的**官方原色** SVG，母題的 `<g>` 一律用 `id="brand-mark"`（`<use href="#brand-mark">` 靠它取用）。
- 其餘漸層／path 的 id 加自己的前綴（如 `acme-*`），避免多標誌並存時撞名。
- 改 `--brand-name` 為該品牌名（不想在標誌旁顯示文字就設成 `""`，並移除【C-1】的文字）。
- 【C】三段的 `width` / `height` 依標誌長寬比調整；`.logo-plate` 的 class 不要動，底片才會跟著主題自動切換。
- 不要在標誌包裡寫任何顏色以外的視覺覆寫（圓角、陰影、字體屬於主題的職責）。
