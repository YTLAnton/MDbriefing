服務項目與報價

Phase 1A 首要優先 單一平台廣告數據 CSV 轉換腳本 ‧ 約 2 週交付 NT$20,000
交付內容
  • 將單一平台之廣告後台匯出的 CSV 自動轉換為結構化可閱讀報表
  • 支援日數據彙整為週報（花費、觸及、轉換率等關鍵指標）
  • 固定格式輸出（HTML 報表或 Excel，依協商確認）
  • 操作說明文件一份
開發啟動前，需由 瀚星文創 提供：單一平台 廣告後台匯出的原始 CSV 範例（至少含 1 週數據，數值可隱匿），以及期望的輸出格式樣本。
Phase 1B 多平台格式擴展 ‧ 於 1A 完成，並確認啟動後約 3 週交付 NT$22,000
交付內容
  • 新增支援三個平台之廣告後台 CSV 格式解析模組
  • 跨平台欄位正規化，統一輸出為一致格式
  • 多平台合併報表，支援廣告組合交叉分析
  • 更新操作說明文件
需由 瀚星文創 提供各平台匯出的原始 CSV 範例檔，以確認各平台欄位格式差異。
Phase 1C 互動式 HTML Dashboard 生成與部署 ‧ 於 1B 完成，並確認啟動後約 3 週交付 NT$28,000
交付內容
  • 將轉換後的廣告數據自動生成互動式 HTML Dashboard
  • Dashboard 部署至指定子網域，供全團隊隨時查閱
  • 歷史數據保存機制
  • 系統維護說明文件
伺服器（VPS / 雲端主機）及子網域由 瀚星文創 自行申請並承擔費用；Anton 協助完成環境部署設定。預估基建費用約 NT$300–600 / 月。
